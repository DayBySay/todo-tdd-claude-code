# Todo App 機能要件

## 概要
シンプルなTodoアプリ。追加・表示・完了・削除・フィルタリングができる。

---

## 機能一覧

### 1. Todo追加
- [ ] テキスト入力欄（placeholder: "What needs to be done?"）
- [ ] 入力後、Enterキーで追加
- [ ] 空文字は追加不可（何も起きない）
- [ ] 追加後、入力欄がクリアされる
- [ ] 追加されたTodoは未完了状態

### 2. Todo一覧表示
- [ ] 追加したTodoがリスト表示される
- [ ] 各Todoにテキストが表示される
- [ ] 各Todoに完了チェックボックスがある
- [ ] 各Todoに削除ボタン（×）がある
- [ ] Todoがない場合は空のリスト

### 3. Todo完了トグル
- [ ] チェックボックスクリックで完了/未完了切替
- [ ] 完了Todoはテキストに打ち消し線（line-through）
- [ ] 完了Todoはチェックボックスがチェック状態

### 4. Todo削除
- [ ] 削除ボタン（×）クリックでTodo削除
- [ ] 削除後、リストから即座に消える
- [ ] 確認ダイアログなし

### 5. フィルタリング
- [ ] フィルタボタン: 「All」「Active」「Completed」
- [ ] All: 全Todo表示
- [ ] Active: 未完了のみ表示
- [ ] Completed: 完了のみ表示
- [ ] デフォルトは「All」
- [ ] 現在のフィルタがハイライト表示

### 6. カウント表示
- [ ] 未完了Todo数を表示
- [ ] フォーマット: "X items left"（X=未完了数）
- [ ] 1件の場合: "1 item left"

---

## 技術要件
- React 18 + TypeScript
- 状態管理: useState
- LocalStorage永続化: スコープ外（今回は不要）
- スタイリング: CSS（最小限でOK）

---

## テスト要件

### ユニットテスト（Vitest）
- Todo追加ロジック
- フィルタリングロジック
- カウント計算ロジック
- コンポーネント単体の振る舞い

### E2Eテスト（Playwright）
- Todo追加フロー
- Todo完了トグルフロー
- Todo削除フロー
- フィルタリングフロー
- 複合操作（追加→完了→フィルタ確認）
